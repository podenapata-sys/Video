# YouTube Shorts posting checklist (Content Rewards: English worldwide, $1 per 1K views)

## One-time setup
1. Create your **custom referral link** (the campaign's "Generating Your Custom Affiliate Link" guide).
2. YouTube Studio → Customization → **Links**: add the referral link (this is mandatory). Put it in the channel description too.
3. **CommentShark** (commentshark.com): connect the channel.
   - Trigger keyword: `LINK` (case-insensitive)
   - Reply: `Here you go 👉 https://whop.com/start/?code=XTWQFG (start with any campaign, it's free)`
4. Turn on monetization-friendly defaults: English, no "Made for kids", comments on.

## Every video
- [ ] **Title:** `Trying to make a doctor salary in 67 mins (comment LINK) #contentrewardspartner`
- [ ] **Description:**
  ```
  Comment "LINK" and I'll send you the link 👇
  https://whop.com/start/?code=XTWQFG
  #contentrewardspartner #sidehustle #makemoneyonline
  ```
- [ ] **Pin a comment:** `Comment LINK for the link 👇 (or tap the link on my channel)`
- [ ] The CTA is said out loud in the video (face-cam, last 4s) and is on screen (automatic).
- [ ] **Submit the video URL in the Content Rewards dashboard.** No submission means no payout.
- [ ] Reply by hand to anyone CommentShark missed, always with your referral link.

## Limits (protect the agency)
- **One video a day, at most 45 minutes** including filming. Batch-film 5 face-cams in one sitting.
- Vary the hook every video, using the brief's list: "while working out", "eating pretzels", "without speaking". Re-film only `hook.mp4`; the steps can be reused.
- Each week, check the % of Tier-1 viewers in YouTube Analytics → Audience → Geography. If it reaches 40%+, switch to the **$3 per 1K** English campaign.
